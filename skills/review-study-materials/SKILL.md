# review-study-materials

Use moodle_list_courses and moodle_list_resources for an explicitly selected authorized course. Keep course, activity and file identifiers with each item. Use returned continuation cursors. Fetch document text only when requested, with the existing file access checks. Label failed reads, omitted items and unavailable coverage. Do not fetch external links with stored credentials. Prepare a short learning outline with evidence references rather than copying all materials into one response.
